# Акты административной комиссии — бесплатный сайт

Статический сайт: три файла HTML, без сервера, без ключей, без лимитов.
Распознавание — в браузере (Tesseract.js, подгружается с CDN, нужен интернет).

Файлы: index.html (меню), fotografirovanie.html, obsledovanie.html.

## Публикация бесплатно
GitHub Pages: репозиторий → загрузить все файлы → Settings → Pages → Deploy from branch (main, /root).
Cloudflare Pages / Netlify: перетащить папку в панель загрузки. Свой домен привязывается в настройках хостинга.

## Нюансы
- Первое распознавание скачивает словарь (~10 МБ), далее кэш.
- Цифры (дата, время, телефон) всегда проверяйте глазами.
- Часть/статью закона, адрес, ФИО указываются вручную. Формулировки нарушений — массивы TF и TV в obsledovanie.html.
